# analise-de-dados
Repositório dedicado a projetos de analise de dados, desde a extração e limpeza (ETL) até a análise exploratória (EDA), modelagem e geração de insigths estratégicos. Desenvolvido em Python (Pandas, NumPy), SQL e  ferramentas de visualização: Power BI, Tableau e QlikView - Python: (Matplotlib, Seaborn ou Plotly).
